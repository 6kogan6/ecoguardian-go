# EcoGuardian

EcoGuardian — это учебный прототип сервиса мониторинга экологических показателей, реализованный на Go.  
Сервис позволяет добавлять датчики, принимать показания, автоматически анализировать их, формировать тревоги и отображать всё в веб-интерфейсе.

## Возможности

- создание датчиков;
- ручное добавление показаний;
- автоматическая генерация данных через симулятор;
- анализ экологических параметров;
- автоматическое создание тревог;
- просмотр состояния через веб-дашборд;
- экспорт данных через API;
- запуск в Docker.

## Технологии

- Go
- Gin
- GORM
- SQLite
- HTML / CSS / JavaScript
- Docker
- Docker Compose
